A Vue template, styled only with Tailwind utility classes (light and dark mode), for a dashboard.
First a responsive grid (1, 2 then 4 columns) of stat cards, one per item of `stats` (keyed by stat.id). Each card: the stat label and an icon badge on one row (the icon is a dynamic component, stat.icon), the big value, a row with the change (green with IconArrowUp when stat.change >= 0, otherwise red with IconArrowDown, text formatPercent(stat.change)) followed by "vs last month", and a Sparkline component with stat.history as points and a green or red color depending on the change.
Below, a card titled "Recent activity" with a "View all" link to /activity, and a list (role list, divided rows) of `activity` events (keyed by event.id): the user's avatar image, a line with the user's name in bold followed by event.description, and a relative time (formatRelative(event.at), in a time element with the datetime bound).

A Vue template for a todo app.
A header with the h1 "Todos" and a form (submit.prevent calls add) holding an autofocused, trimmed input bound to draft, with a placeholder.
A main section, shown only when there are todos: a toggle-all checkbox (checked when remaining is 0, change calls toggleAll) with its label, then a TransitionGroup rendered as a ul (name list) with one li per todo in filtered (keyed by todo.id, classes completed and editing). Each li shows either a view (a checkbox bound to todo.done, the title in a label that calls edit(todo) on double click, and a delete button calling remove(todo)), or, while it is the one being edited, an edit input bound to todo.title with a v-focus directive, which calls done(todo) on blur and on Enter and cancel(todo) on Escape.
A footer, shown only when there are todos: the count of remaining items with "item" or "items" and "left", a list of filter links (one per entry of the filters object, linking to #/<key>, class selected for the current visibility), and a "Clear completed" button shown only when some are done.
A named slot "footer" receiving the todo count, whose fallback content is a hint about double-clicking to edit and a "Made with Vue" link.

# Agent rules

A compact description of zamn for coding agents. Paste it into `AGENTS.md`,
`CLAUDE.md`, `.cursor/rules` or a system prompt, or point your agent at it.

```sh
curl -fsSL https://zeokku.github.io/zamn/downloads/zamn-agent-rules.md >> AGENTS.md
```

of this documentation.
